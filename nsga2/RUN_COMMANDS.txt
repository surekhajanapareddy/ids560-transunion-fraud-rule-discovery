NSGA-II commands (run from the "code" folder).
Put synthetic_fraud_500k.csv in the code folder, or replace the file name with its full path.
NOTE: the "out" folders below are the saved results. Running a command overwrites them, so use a different folder name if you want to keep the originals.

INSTALL (once):
  pip install numpy pandas matplotlib deap pymoo scikit-learn optuna

ARGUMENT ORDER
  nsga2_midterm.py    csv  pop  gens  seed                                  (6 features)
  nsga2_allfeatures.py csv pop  gens  seed  crossover  mutation  out_folder  condition_cap   (all features)

EXPERIMENT 1  - 6 features, pop 100, 150 gens, crossover 0.7, mutation 0.5
  mkdir -p ../results/exp1_6features && cd ../results/exp1_6features && python ../../code/nsga2_midterm.py ../../code/synthetic_fraud_500k.csv 100 150 42 && cd ../../code

EXPERIMENT 2  - all features, pop 100, 150 gens, 0.7 / 0.5
  python nsga2_allfeatures.py synthetic_fraud_500k.csv 100 150 42 0.7 0.5 ../results/exp2_allfeatures 160

EXPERIMENT 3  - all features, pop 60, 100 gens, crossover 0.5, mutation 0.2
  python nsga2_allfeatures.py synthetic_fraud_500k.csv 60 100 42 0.5 0.2 ../results/exp3_allfeatures 160

EXPERIMENT 4  - all features, pop 200, 250 gens, crossover 0.9, mutation 0.8
  python nsga2_allfeatures.py synthetic_fraud_500k.csv 200 250 42 0.9 0.8 ../results/exp4_allfeatures 160

EXPERIMENT 5  - lower mutation (0.2), otherwise same as Exp 4
  python nsga2_allfeatures.py synthetic_fraud_500k.csv 200 250 42 0.9 0.2 ../results/exp5_lower_mutation 160

EXPERIMENT 6  - 50-condition cap, otherwise same as Exp 4
  python nsga2_allfeatures.py synthetic_fraud_500k.csv 200 250 42 0.9 0.8 ../results/exp6_cap50 50

OPTUNA SEARCH (24 trials, pop 200, 2 workers, about 35 min)
  python nsga2_optuna.py synthetic_fraud_500k.csv 24 200 ../results/optuna 2
  Re-check a fixed setting with the same seeds (for a fair comparison):
  python optuna_baseline.py synthetic_fraud_500k.csv 200 250 0.9 0.8 baseline_same_seeds.csv

SCIKIT-LEARN STYLE PARAMETER SEARCH (12 settings x 3 seeds, about 35 min)
  python nsga2_search.py --csv synthetic_fraud_500k.csv --n_iter 12 --seeds 3 --pop 200 --out ../results/parameter_search/nsga2_search
  (--n_iter 0 = full grid; --gens / --cx / --mut take comma-separated value lists; if it is interrupted, run the same command again and it resumes)

RANDOM FOREST BENCHMARK + FEATURE IMPORTANCE (about 90 s)
  python rf_benchmark.py synthetic_fraud_500k.csv

REDRAW ALL GRAPHS FROM THE SAVED CSVs
  python make_plots.py

QUICK TEST (about 1 minute, tiny settings)
  python nsga2_allfeatures.py synthetic_fraud_500k.csv 40 5 42 0.7 0.5 quick_test 160
